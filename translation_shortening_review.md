**Implementation status:** approved short labels in this review are applied to repeated player-facing UI labels, and `translation_list.md` now reflects the implementation. `Keep current` content and full wording in sentences and helpers remain unchanged; no layout or image changes were made.

## Evidence and limits

- **Observed:** the source inventory contains 136 grouped rows: 49 C# rows (377 semicolon-separated copy occurrences across 43 C# files) and 87 serialized/non-C# rows. I reviewed all row dispositions in both audits and checked the short-label candidates below against the exact English/current strings in `translation_list.md` and their named owners. The audit details are summarized here so this review does not depend on temporary files.
- **Observed:** `QA/localization_verification.md` records that the Main Menu `Piliin ang Antas` label touched both button edges in a Simulator capture. It does not establish clipping and is historical evidence, not a current-session rendering check.
- **Observed:** static layouts include a 260×76 UI-unit discovery-dismiss button at 42pt with no wrap/autosizing and truncate overflow; a hint confirmation button preferred size of 250×64 UI units in a two-button row with 40→28pt autosizing and no wrap; and a 720×140 UI-unit Main Menu button with a fixed 56pt label, wrapping horizontally and truncating vertically. Serialized Settings SFX/BGM labels are fixed 20pt in 35% of a parent whose effective dimensions are **UNKNOWN**. Gameplay's instruction frame is 524×144 UI units at 54pt. These are authored canvas units, not physical phone pixels.
- **Inference:** longer labels in fixed or narrow controls carry fit risk, but character ratios do not predict glyph width or establish overflow. The discovery dismiss label has a source-defined truncate mode; actual clipping remains **NOT VERIFIED**. The Main Menu button has a historical crowding observation; actual clipping/current fit remains **NOT VERIFIED**. Other frame risks below are not claims of current overflow.
- **Implementation:** all distinct short-label forms in the table have been applied as wording changes. Any layout adjustments remain recommendations only; none were made. Labels without an approved short form remain unchanged pending a live fit check.

Character counts below were recalculated programmatically from the exact visible English/current strings in the inventory, counting spaces and punctuation, excluding rich-text markup and treating interpolation tokens as protected/length-neutral. Ratios are current Filipino characters divided by English characters. A ratio of 1.5 or more is a review trigger, not a fit verdict.
